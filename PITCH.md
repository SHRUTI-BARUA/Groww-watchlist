Most watchlists answer "where are things now?" —  answer for this is "what changed since you last looked, and does it actually matter?" That's a fundamentally different problem: a diff problem plus a signal-vs-noise problem.

I built a composite Attention Score (0–100) — normalizing price moves by each stock's own volatility, not an arbitrary 2% threshold — and paired it with a one-line plain-English reason. Because a score without a reason isn't a product.

Under the hood, a shared-polling worker serves N users watching RELIANCE with one API call, not N.
